# AI Assistance

AI tools were used during the development of this project as a learning and development aid.

## Areas Where AI Was Used

### Project Planning

AI was used to help structure the project workflow and organize the different components of the system.

### Python Development

AI assistance was used to:

- Understand Python concepts.
- Debug Python errors.
- Improve code structure.
- Understand Pandas operations.
- Troubleshoot data-processing issues.

### SQL

AI was used to:

- Understand SQL concepts.
- Practice business-oriented SQL queries.
- Debug SQL queries.
- Improve query logic.

### Machine Learning

AI assistance was used to understand:

- Feature preparation.
- Train/test splitting.
- Logistic Regression.
- Model evaluation.
- Risk-score calculation.
- Risk-level classification.

The machine-learning workflow was implemented and tested as part of the project.

### Streamlit

AI was used to help with:

- Streamlit application structure.
- UI organization.
- Login and role-based access logic.
- Dashboard layout.
- Debugging application errors.

### Documentation

AI assistance was used to improve the organization and clarity of the project documentation.

## Human Contribution

The project was developed as a hands-on learning project.

The author was responsible for:

- Understanding the project requirements.
- Working with the datasets.
- Running and testing the code.
- Performing data analysis.
- Building SQL analysis.
- Creating Power BI dashboards.
- Implementing the machine-learning workflow.
- Testing the Streamlit application.
- Reviewing and modifying AI-assisted suggestions.

AI was used as a development assistant, not as a replacement for understanding and testing the project.

## Learning Objective

The primary purpose of using AI assistance was to improve problem-solving ability, understand unfamiliar concepts, debug errors, and develop practical data-analytics skills.
